This is a small Godot application which simulates a double pendulum starting from various starting angles for a given time, and projects the final angular positions to a graph according to different functions, producing some fascinating colored fractals.

Has controls for step precision, time, and which function to use for the graphics. The simulation is implemented in a shader, so it runs blazingly fast on anything with a GPU. It even runs pretty well on my phone!

Should be compatible with anything Godot can build to, but i've only tested it on windows and android.
